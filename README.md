## ✨ 核心亮点功能

### 1. 📚 1000 题全真题库，各模块进度独立记忆
* **全部题库 (1000 题)**：单选题 800 题 + 判断题 200 题独立专练。
* **历年分卷专区**：收录 2024 年全真模拟卷及历年原卷（卷一至卷四，共 5 套）。
* **考场模拟与快速自测**：支持 120 分钟全真倒计时模考与 50 题碎片化自测。
* **各模块独立游标**：做单选不冲掉做判断题的题号，做试卷不影响总题库游标。

### 2. 📲 跨设备无缝双向同步 (Zero-Server 技术)
* **电脑 ➔ 手机（微信扫一扫）**：点击「跨端同步」即刻生成高密动态二维码，手机一扫秒同步当前所有作答进度、错题与收藏！
* **手机 ➔ 电脑（口令/链接互传）**：手机一键复制专属同步链接发送到微信，电脑端微信点开即可自动弹窗同步。
* **数据加密压缩**：采用 LZ-String 高压缩算法，千道题目记录压缩至两三百字符，仅在前端 URL Hash 解析，100% 隐私安全。
* **智能合并 (Smart Merge)**：两台设备答题记录取并集叠加，错题本与收藏夹去重融合，永不丢失任何记录；亦提供「完全覆盖」选项。

### 3. 🔍 专业级电路图手势无级视口
* 收录题库内全部 **93 张高清电气原理图与电路排故图**。
* 支持**手机双指捏合缩放**、**触控板 Pinch 手势**、**鼠标滚轮缩放**与**拖拽平移**，双击复位，电路细节分毫毕现。

### 4. 🌙 护眼与个性化阅读系统
* **三大护眼主题**：经典浅白 / 护眼暖黄纸质 / 深色夜间模式，自由切换。
* **字号无级调节**：标准 / 大字 / 特大字，关照全年龄备考考生。
* **智能自动翻页**：答对 800ms 舒适微延时自动跳转下一题，答错停留在原地强化解析。

### 5. 💾 进度备份与数据恢复
* 支持本地导出 `.json` 进度备份文件。
* 支持一键导入备份文件恢复做题记录，支持智能合并与完全覆盖。

## 📂 项目结构

```text
electric-master/
├── index.html            # GitHub Pages 主入口（自包含单文件版本，离线秒开）
├── README.md             # 项目说明文档
├── .nojekyll             # GitHub Pages 静态构建标记
├── 一键启动刷题.bat       # Windows 本地一键启动轻量本地服务器
├── data/                 # 结构化题库数据库与电路图片资产
├── dist/                 # 预打包单文件产物
├── scripts/              # 题库构建与打包脚本
└── web/                  # Web 前端开发源码（HTML/CSS/JS/Libs）
```

## 🛠️ 本地运行指南

1. **直接双击**：进入 `dist/` 目录双击 `高级电工刷题系统_单文件离线版.html`，无需安装任何软件直接开刷。
2. **本地局域网服务**（支持同 Wi-Fi 下手机局域网做题）：
   双击根目录下的 `一键启动刷题.bat`，即可自动启动微服务并在浏览器中打开。
