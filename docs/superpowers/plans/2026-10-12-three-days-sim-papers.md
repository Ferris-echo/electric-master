# 2026年10月21/22/23日三套考前精简特训卷及全新交互体验升级 Plan

> **Goal:** 本地全量集成 10月22日与23日两套全新电工模拟卷（全库扩充至 1630 题），实现“首次进入考期自选引导弹窗”、“日期分段选择机制”、“顶部与卡片双入口一键看答案/背题”、“侧边栏与菜单展开高级丝滑动画”，并在本地完成打包与测试供用户预览，严守“用户确认前绝不推送到 GitHub Pages”的纪律。

---

## 用户的明确指令与要求约束
1. **工作流程原则**：必须先在本地完整修改并测试打包，供用户在本地浏览器查看效果；用户同意后方可推送到 GitHub Pages。
2. **首次进入弹窗（考生考期定向引导）**：首次访问时弹出精致对话框，询问用户是 21号 / 22号 / 23号 考生，点击后自动选中对应日期并直接跳转到该卷刷题。后续支持随时修改。
3. **显示答案/背题功能上移与常驻**：
   - 顶部工具栏（与跨端同步、题号抽屉等同排）增加高辨识度【👁️ 背题模式】一键切换按钮；
   - 刷题卡片内部（右上角收藏星标旁边）增设【💡 显示本题答案】速查按键，点击即可快速展开/折叠当前题目的标准答案与解析，极大提升极速背题体验。
4. **菜单与抽屉展开高级动画**：
   - 移动端点击展开菜单/侧边栏时，提供流畅的 `cubic-bezier` 滑入展开动画与毛玻璃遮罩淡入；
   - 题号抽屉、弹窗等增加弹出微动效，视觉体验丝滑自然。
5. **保证 UI 简洁清晰**：采用 2026 日期分段切换器（Segmented Tabs），复用紧凑卡片，杜绝侧边栏无限堆叠。
