# 高级电工刷题程序 · 国内直连永久上线指南

> 💡 **核心优势**：
> - **100% 国内网络直连秒开**（腾讯云国内电信/联通/移动节点加速，延迟 < 30ms，无需翻墙）；
> - **完全免费**，免买服务器，免域名备案；
> - 永久拥有一个 HTTPS 专属网址和二维码，发给任何人随时随地都能刷。

---

## 方案 A：腾讯云 EdgeOne Pages（⭐ 最推荐，全国秒开）

### 第 1 步：访问腾讯云 EdgeOne Pages 控制台
1. 打开浏览器访问：[https://edgeone.ai/products/pages](https://edgeone.ai/products/pages) 或登录腾讯云搜索 **EdgeOne Pages**；
2. 使用微信扫码即可免费登录（新老用户均有永久免费个人额度）。

### 第 2 步：上传项目文件夹
1. 在控制台点击 **“创建项目”**（Create Project）；
2. 选择 **“直接上传文件夹 / 静态资源上传”**（Upload Folder）；
3. 将我们电脑目录中的 **`web` 文件夹** 直接拖拽到网页上传框中；
4. 项目名称填写：`electrician-exam`（或任意自定义英文）。

### 第 3 步：点击部署并获取网址
1. 点击 **“开始部署”**（Deploy），约 5~10 秒钟自动部署完成；
2. 页面会立刻生成一个官方专属二级域名，例如：
   `https://electrician-exam.edgeone.app`
3. 复制该链接，或使用草料二维码（cli.im）将链接生成二维码图片。

## 方案 B：纯单文件版（零服务器，离线胶囊）

如果你不想在任何网站部署，我们已经为你准备好了完全单文件的离线版本：
- 文件路径：`dist/高级电工刷题系统_单文件离线版.html`
- **使用方法**：
  1. 电脑端：直接双击此 HTML 文件即可在浏览器中全屏使用；
  2. 手机端：可以通过微信“发送文件”发到手机，或在电脑运行 `一键启动刷题.bat` 后手机扫码添加至主屏幕。

## 手机端“添加到主屏幕”秒变原生 App 指南

### 🍎 苹果 (iPhone / iPad) 用户：
1. 用 **Safari 浏览器** 打开刷题网址；
2. 点击屏幕底部的 **“分享”** 按钮（方框带向上箭头图标）；
3. 往下滑动，点击 **“添加到主屏幕”**（Add to Home Screen）；
4. 手机桌面上就会出现带有金色闪电图标的 **“高级电工刷题”** 原生体验 App，支持离线运行。

### 🤖 安卓 (Android) 用户：
1. 用系统自带浏览器或 Chrome / 微信打开刷题网址；
2. 点击右上角菜单按钮（三个点）；
3. 选择 **“添加到主屏幕”** 或 **“安装应用”**。
